## 6. DiffScopeGuard Capabilities

### Guard (diff-scope-guard.ts)
- `evaluateDiffScope` — strict/advisory dual mode, forbidden priority, overlap detection
- `pathMatchesRule` — exact / directory-slash / directory-no-slash / `/**` / non-similar-prefix protection
- `normalizeFilePath` / `normalizePathList` — backslash→slash, trim, dedup, first-occurrence order

### Reporter (diff-scope-reporter.ts)
- `buildDiffScopeEvidence` — Guard result → `EvidenceRecord` (type: code_review)
- `renderDiffScopeMarkdown` — 9 sections with table escaping
- `writeDiffScopeReport` — atomic JSON+MD write, creates outputDir recursively

### Scenario Runner (diff-scope-scenario-runner.ts)
- `DiffScopeScenario` — id/title/intent/changed_paths/mode/expected_allowed/notes
- `runDiffScopeScenario` — evaluate→evidence→report, expected_allowed assertion
- `runDiffScopeScenarios` — serial batch with total/passed/failed, order-preserving
- `sanitizeDiffScopeScenarioId` — alphanumeric+_- only

### Git Diff Adapter (git-diff-adapter.ts)
- `getChangedPathsFromGitDiff` — default/staged/refs/untracked modes
- `defaultGitCommandRunner` — `child_process.execFile` (no shell injection)
- `parseGitNameOnlyOutput` / `normalizeGitDiffPath`
- Ref validation — whitespace/`;`/`&`/`|` prohibited
- Injectable runner for zero-real-git tests

### Manual Audit CLI (project-brain-diff-scope-audit.cjs)
- Full CLI with `--help` and 9 flags
- End-to-end: intent lookup → git diff → scenario runner → JSON/MD report
- **NOT a Git Hook, NOT a Sentinel, NOT a blocker**
